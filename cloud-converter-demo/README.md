# CloudConverter 시연 버전 (Windows)

「Cloud Converter UI 고도화 기획」(변경 이력 V1.4 기준)을 바탕으로 만든 **오프라인 시연용** Windows 프로그램입니다.
인터넷 연결 없이 동작하며, **실제 MIP/DRM 암호화는 수행하지 않습니다.**
(프로그램 정보 창에 "본 애플리케이션은 시연용으로, 실제 MIP 변환 기능을 제공하지 않습니다." 문구가 항상 표시됩니다.)

- 대상 환경: Windows 11 x64, FHD (Windows 10 에서도 실행 가능). 디스플레이 배율(DPI)에 맞춰 자동 확대
- 형태: 단일 실행 파일 `CloudConverter.exe` (.NET 8 포함, 설치 불필요) + `config` 폴더

## 실행

1. `CloudConverterDemo` 폴더를 원하는 위치에 복사합니다. (exe 와 `config` 폴더는 같은 위치에 두어야 합니다.)
2. `CloudConverter.exe` 를 실행합니다.
   - 처음 실행 시 탐색기 우클릭 메뉴가 자동 등록됩니다. (현재 사용자 레지스트리(HKCU), 관리자 권한 불필요)
   - 처음 실행 시 시연용 샘플 파일이 생성됩니다. → `문서\CloudConverterDemo\`
3. Windows SmartScreen 경고가 뜨면 "추가 정보 → 실행"을 누릅니다. (코드 서명이 없는 exe 이기 때문입니다.)

> exe 위치를 옮긴 경우, 다시 한 번 실행하면 우클릭 메뉴가 새 위치로 자동 갱신됩니다.

## 시연 시나리오

| # | 시나리오 | 방법 |
|---|---|---|
| 1 | 바로가기 실행 | exe 실행 → 빈 상태, `변환할 형식` 선택 전에는 모두 비활성 |
| 2 | 탐색기 우클릭 실행 | 문서 우클릭 → (Win11: **더 많은 옵션 표시**) → `CloudConverter(demo)` ▶ `MIP로 변환` / `DRM으로 변환` → 형식이 선택되고 파일이 들어간 상태로 실행. 여러 파일을 한 번에 선택해도 창은 하나만 뜹니다. |
| 3 | 드래그 앤 드롭 | 탐색기에서 파일/폴더를 `대상파일/폴더` 목록에 끌어다 놓기 |
| 4 | 찾기 | `내 드라이브` → 파일 선택 / 폴더 선택, `OneDrive`·`SharePoint` → 가상 클라우드 탐색 창 |
| 5 | 변환 | 저장 위치 선택 또는 `대상 파일과 동일 폴더에 저장` → `변환 시작` → 확인 팝업 → 진행 상태 표시 |
| 6 | 결과 확인 | 변환할 파일이 모두 `준비 중`으로 올라간 뒤 순서대로 진행. 성공(파란 막대 100%), 실패(회색), SKIP(연한 파랑), 폴더 변환 시작/완료, 마우스를 올리면 사유 툴팁 |
| 7 | 로그 보기 | 조회 기간, 결과 필터, 검색어, 상세 보기, CSV 내보내기 |

### 샘플 파일 (`문서\CloudConverterDemo\샘플 문서`)

| 파일 | MIP 변환 결과 |
|---|---|
| 제안서_초안.docx, 견적서.xlsx, Company Profile.pdf | 성공 |
| 이미 암호화된 보고서.docx | 실패 - 이미 암호화된 파일 (실제로 암호화된 Office/PDF 파일도 같은 방식으로 감지) |
| 권한없음_fail.docx | 실패 - 레이블 변환 권한 없음 (파일명에 `_fail`) |
| 빈 파일.docx | SKIP - 파일 크기 0 |
| readme.txt | 목록에서 `불가`, 변환 시 SKIP - 지원하지 않는 확장자 |
| 프로젝트 폴더 (하위 폴더 포함) | 폴더 변환 시작/완료 + 내부 파일 진행 |

- **프로그램을 실행할 때마다 모든 파일이 암호화되지 않은 상태로 시작합니다.** 실행 중에 변환한 파일(결과 파일, 동일 폴더 저장 시 원본 자리)을 같은 형식으로 다시 변환하면 **이미 암호화된 파일**로 실패합니다. (MIP 변환한 파일을 DRM으로 변환하는 것은 가능) 프로그램을 닫았다가 다시 실행하면 처음 상태로 돌아가므로 같은 시연을 반복할 수 있습니다.
- 파일명에 `_skip` 이 있으면 "정책에 의한 스킵"이 됩니다.
- 프로그램 정보(ⓘ) 창의 `샘플 폴더 열기` 로 샘플 폴더를 바로 열 수 있습니다.

### 가상 OneDrive / SharePoint (`문서\CloudConverterDemo\Cloud`)

오프라인 시연을 위해 클라우드는 로컬 폴더로 흉내 냅니다. 화면에는 `OneDrive\문서\...`, `SharePoint\영업팀\...` 처럼 클라우드 경로로 표시됩니다.
- `Cloud\OneDrive\` 아래 파일 → OneDrive
- `Cloud\SharePoint\<사이트명>\` 아래 파일 → SharePoint 사이트 (사이트 목록은 `demo-settings.json`)
- 시연 전에 이 폴더에 원하는 파일을 넣어 두면 그대로 보입니다.

### MIP 확장자 변환 규칙

[MIP SDK 지원 파일 형식](https://learn.microsoft.com/ko-kr/information-protection/develop/concept-supported-filetypes) 기준으로 `config/extension-rules.json` 에 정의되어 있습니다.

- Office(Word/Excel/PowerPoint) · PDF: 네이티브 보호, **확장자 유지** (`보고서.docx` → `보고서.docx`, `a.pdf` → `a.pdf`)
- 텍스트·이미지: `p` 접두 (`.txt` → `.ptxt`, `.jpg` → `.pjpg`, `.png` → `.ppng` …)
- 그 외: 일반 보호 `.pfile` (`a.zip` → `a.zip.pfile`)
- DRM 변환은 원본 확장자를 유지하고, MIP 보호 확장자는 원래대로 되돌립니다 (`.ptxt` → `.txt`).

현재 허용 확장자는 Office·PDF 뿐이므로 실제 시연에서는 확장자가 바뀌지 않습니다. `AllowedExtensions` 에 `.txt` 등을 추가하면 위 규칙대로 확장자가 바뀝니다.

## 설정 파일 (`config` 폴더)

파일을 수정한 뒤 프로그램을 다시 실행하면 반영됩니다. 파일이 없거나 형식이 잘못되면 기본값을 사용하고 시작할 때 알려 줍니다.

| 파일 | 내용 |
|---|---|
| `demo-settings.json` | 창 제목, 제품명, 계정, 버전, 저작권 문구, 가상 클라우드 위치·SharePoint 사이트 목록, 샘플 생성 여부, 우클릭 메뉴 자동 등록 여부 |
| `extension-rules.json` | 허용 확장자, MIP 보호 시 확장자 변환 규칙 |
| `conversion-policy.json` | 형식별 대상→저장 위치 조합, 한 번에 변환 가능한 개수/용량(0 = 제한 없음), 제외 디렉토리·키워드, 시연용 강제 실패/스킵 키워드, 진행 속도 |
| `log-classification.json` | **로그 결과 분류.** 결과 그룹(성공/실패/스킵/알림…)과 결과 코드별 분류·사유 문구 |

### 로그 결과 분류 교체 (기획서 20p 문의사항 대응)

로그에는 결과 **코드**만 저장하고, 화면에 보이는 결과(성공/실패/스킵)와 분류 문구는 `log-classification.json` 이 정합니다.
분류 기준이 확정되면 이 파일만 바꿔 넣으면 되고, **이미 쌓인 로그도 새 분류로 다시 보입니다.** (로그 뷰어를 열 때마다 다시 읽습니다.)

```jsonc
// 예: "이미 암호화된 파일"(2003)을 실패 대신 새 그룹 "보류"로 분류
"Groups": [ ..., { "Id": "hold", "Display": "보류", "Style": "Skip" } ],
"Codes":  [ ..., { "Code": 2003, "Group": "hold", "Category": "이미 암호화된 파일", "Reason": "이미 암호화된 파일" } ]
```

`Style` 은 진행 상태 막대 모양입니다: `Success`(파란색) / `Fail`(회색) / `Skip`(연한 파랑) / `Info`(문구).

| 코드 | 기본 분류 |
|---|---|
| 1000 / 1001 | 성공 - MIP / DRM 변환 성공 |
| 2001 / 2002 / 2003 | 실패 - 이미 암호화된 파일 (MIP / DRM / 실제 암호화 감지) |
| 2004 / 2005 / 2006 | 실패 - 파일 접근 실패 / 레이블 변환 권한 없음(시연용) / 원본 없음 |
| 3001 / 3002 / 3003 / 3004 / 3005 | 스킵 - 대상 확장자 아님 / 크기 0 / 정책에 의한 스킵 / 제외 디렉토리 / 사용자 작업 중지 |
| 9001 / 9002 | 알림 - 폴더 변환 시작 / 완료 |

## 문제 해결: 모든 파일이 "이미 암호화된 파일"로 실패할 때

실패 막대에 마우스를 올리거나 로그 보기 → 상세 보기의 **분류 코드**로 원인을 구분할 수 있습니다.

| 분류 코드 | 원인 | 해결 |
|---|---|---|
| 2001 (시연 변환 기록) | 지금 실행 중에 이미 변환한 파일입니다. 특히 `대상 파일과 동일 폴더에 저장`으로 변환하면 샘플 원본 자리에 결과가 저장되므로, 그 뒤로는 같은 샘플이 "이미 변환된 파일"이 됩니다. | 프로그램을 닫았다가 다시 실행 (실행할 때마다 처음 상태로 초기화) |
| 2003 (암호화 감지) | 파일 내용이 실제로 암호화되어 있습니다. 시연 PC 의 MIP 클라이언트/백그라운드 컨버터 등이 샘플 문서를 자동으로 암호화했을 수 있습니다. | `config\conversion-policy.json` → `"DetectEncryptedFiles": false` 로 바꾸고 다시 실행 (이 경우 `이미 암호화된 보고서.docx` 샘플도 성공으로 바뀝니다) |

같은 시연을 반복할 때는 프로그램을 다시 실행하면 항상 같은 결과가 나옵니다.

## 우클릭 메뉴 등록 / 해제

- 자동: 실행할 때 등록 (`demo-settings.json` → `AutoRegisterContextMenu`)
- 수동: 프로그램 정보(ⓘ) 창의 `탐색기 우클릭 메뉴 등록/해제` 버튼, 또는 명령줄 `CloudConverter.exe --register` / `--unregister`
- 등록 위치: `HKCU\Software\Classes\SystemFileAssociations\<확장자>\shell\CloudConverterDemo`, `HKCU\Software\Classes\Directory\shell\CloudConverterDemo`
- **Windows 11** 의 새 우클릭 메뉴(첫 화면)에는 코드 서명된 패키지 앱만 들어갈 수 있어, 이 시연 버전은 **"더 많은 옵션 표시"(또는 Shift+우클릭 / Shift+F10)** 메뉴에 나타납니다.

## 빌드 (개발자용)

```powershell
# Windows, .NET 8 SDK
.\build.ps1      # 테스트 실행 → dist\CloudConverterDemo\ 와 dist\CloudConverterDemo.zip 생성
```

구성:
- `src/CloudConverter.Core` - 정책, 확장자 규칙, 파일명 중복 규칙, 변환 엔진, 로그 (플랫폼 독립, 단위 테스트 대상)
